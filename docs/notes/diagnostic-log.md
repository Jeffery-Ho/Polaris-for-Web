# Polaris 诊断日志

## 目的

诊断日志用于排查窄视口下导航拖动偶发失效、路由切换后状态残留、页面隐藏或窗口失焦等问题。日志仅保留当前标签页会话，不新增网络权限，也不提供后台上传服务。

## 采集内容

- 版本和构建号、当前支持平台、语言、粗粒度浏览器和系统摘要。
- 当前视口宽高和设备像素比。
- 拖动的 `pointerdown`、激活、正常释放或异常取消原因，以及是否发生指针捕获。
- 路由变化、扫描和渲染数量摘要。
- 扩展错误的错误类型名称，不保存错误消息或堆栈。

事件使用白名单字段，最多保留 200 条且有序列化大小上限。日志不包含 AI 正文、Marker 标题、完整 URL、账号信息、提示词、Cookie、令牌或堆栈。

## 导出流程

设置页的“发送诊断日志”会先下载脱敏 JSON，然后打开收件人为 `jefferyho.build@gmail.com` 的系统邮件草稿。浏览器不能可靠地为 `mailto:` 自动添加本地附件，因此需要用户手动附加刚下载的 JSON 文件。

“仅下载日志”只保存 JSON 文件，不打开邮件入口。若系统没有邮件客户端，仍可使用该按钮交付日志。

导出失败不会影响导航功能；设置页会显示失败或下一步操作状态。关闭标签页后，当前会话日志随 `sessionStorage` 会话清除。
