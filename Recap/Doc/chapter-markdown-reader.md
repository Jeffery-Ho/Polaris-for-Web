# 章节 Markdown 阅读优化

## 需求

- 章节视图需要更完整地展示网页 AI 回复已渲染的 Markdown 正文。
- 保留标题、强调、删除线、行内与块代码、链接、引用、嵌套列表、任务列表、表格和图片。
- 图片按原比例内嵌，点击后在新标签查看；复制章节和全文仍只输出纯文本。

## 实现

- 新增章节 Markdown 白名单，仅重建可读语义元素；脚本、样式、iframe 和未知节点不会进入章节正文。
- 普通链接仅允许 `http`、`https`、`mailto`；图片仅允许页面既有的 `http` 或 `https` 地址。
- 复杂表格保留表头、表体、表尾、caption 与单元格跨行/跨列；列表保留嵌套结构和禁用的任务复选框。
- 图片失败时移除对应预览，不阻塞其余章节正文。

## 验证

- `pnpm test`
- `pnpm check`
- `pnpm build` 后检查 `dist/manifest.json` 为 `0.31.0(133)`。
- 重新加载未打包扩展，在真实长回答页面检查 Markdown 语义、图片点击、横向表格滚动、纯文本复制与亮暗主题。
