# 关于与反馈入口

- 右侧控制胶囊的第三个 Tab 显示为“关于 / About”，但继续承载原有的导航配置：最大 marker 数量、折叠阈值、提示宽度、Marker 类型筛选与重置。
- 配置面板 Footer 左侧保留 `chrome.storage.sync` 状态；右侧使用仅图标入口提供反馈。
- 邮件图标使用 `mailto:jefferyho.build@gmail.com` 调起默认邮件客户端。
- Issue 图标在新标签页打开 `https://github.com/Jeffery-Ho/Polaris-for-Web/issues`。
- 两个图标均提供本地化悬停提示与 ARIA 标签，并沿用 Polaris 亮暗主题的悬停和键盘焦点样式。
