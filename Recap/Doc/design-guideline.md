# Design Guideline

## BoomBranch-like Glass Theme

- 全局扩展控件使用亮色/暗色自适应 glass 视觉。
- 暗色模式使用接近 BoomBranch 的深色半透明背景、`white/10` 级别细描边、柔和暗色阴影和轻内高光。
- 亮色模式沿用此前 Polaris 浅白玻璃背景，保留低对比描边和柔和阴影。
- marker、设置按钮、收起按钮、设置菜单、输入框、选项和重置按钮必须优先继承共享 glass 变量。
- 非交互态的 marker 与顶部按钮背景必须和设置面板共用 `--gpt-glass-bg`，避免同一导航出现不同底色。
- marker 与顶部按钮的 hover 背景必须复用重置按钮的 `--gpt-arco-fill-3`，选中态保留强调色。
- marker 不使用柔和投影，仅保留一像素 glass 描边；设置面板与顶部按钮的投影不受影响。

## 顶部控制胶囊

- 导航、章节和关于与设置入口合并为单一三 Tab 玻璃胶囊，默认选中“导航”；“关于与设置 / About&Settings”沿用既有配置面板能力。
- 再次点击已选中的“导航”Tab 时切换 marker 队列的收起和展开；章节 Tab 打开既有阅读弹层；设置 Tab 通过点击显示配置面板，不依赖悬停。
- 胶囊 Tab 与悬浮 active marker 使用一致的主题化选中态：浅色模式黑底白字，深色模式白底黑字；AI maker 数量折叠分组展开后保持原有玻璃背景，悬停时仅增加同色背景不透明度。
- 胶囊外层的上下、左右内边距均为 3px；外层最小内容高度必须与 Tab 高度一致，避免选中 Tab 的上下留白大于左右留白。
- 切换未选中的 Tab 时，选中背景作为胶囊内独立指示层，在旧、新 Tab 间平移并同步调整宽度，形成 iOS 风格的滑动选中效果。
- 胶囊左上角的圆形图标按钮仅在悬停或键盘聚焦时显示；展开状态显示减号以执行最小化，最小化状态显示斜向双箭头以执行最大化。最小化后仅保留当前选中 Tab，其余 Tab 隐藏，导航仍保留既有的视口四周安全留白。最小化状态应跨支持站点同步，且不得关闭已打开的设置面板。
- 整个控制胶囊可作为拖拽手柄；最小化后同样允许拖拽。超过拖拽阈值后显示抓取态、禁用文本选择，并把自由位置以相对视口的 `top/right` 偏移同步保存。重置设置时恢复默认右上角位置；设置面板不再提供 Top gap 或 Right offset。
- 自由定位时控制胶囊、搜索框、设置面板和 marker 队列仍共享同一右边缘；视口缩小时仅临时将胶囊夹紧在可见范围内。
- 深色模式下普通 marker 保持玻璃背景；hover、选中和悬浮 active marker 使用白底黑字。
- 深色模式的 marker 覆盖规则必须位于其基础样式之后，确保选中和悬浮 active marker 不会被默认深色样式覆盖。
- 设置菜单打开后，按 Escape 或点击胶囊和设置面板外的页面区域应返回“导航”Tab；章节弹层打开时 Escape 优先关闭章节弹层。
- 设置 Tab 激活时，隐藏 marker 队列、搜索框和悬浮 active marker，仅显示设置面板；返回导航 Tab 后恢复这些导航内容。
- “导航”Tab 使用原插件小图标、标题和展开/收起箭头；设置与导航 Tab 切换只更新控件状态，避免不必要的标题重新采集。
- 所有新增固定前台文案与 ARIA 标签必须先加入全局国际化词典；浏览器语言以 `zh` 开头时使用中文，其余语言使用英文，缺失键回退英语。AI 正文、章节标题与 marker 标题保持页面原文。
- Tab 使用选中态、键盘方向键切换和可见焦点；设置面板保持现有同步状态、配置字段、类型筛选与重置能力。

## 设置面板

- 设置面板使用固定 Header、可滚动内容区和固定 Footer：Header 仅展示应用图标和 Polaris；内容区顶部以次级文本显示当前支持的平台；Footer 左侧展示版本号（`版本号(build号)`），右侧展示邮件和 GitHub 图标入口。
- Footer 联系入口仅使用图标显示，悬停提示与 ARIA 标签必须说明操作；邮件使用 `mailto:`，Issue 在新标签页打开。两个入口使用 Hero 风格圆形 ghost 按钮，默认半透明表面与细描边，亮暗主题下均沿用主题高亮与可见焦点。
- 设置面板宽度必须与顶部 Tab 胶囊相同，并随胶囊宽度变化；视口不足时共同受可视宽度限制。
- Header 与 Sync Footer 不使用额外组件默认外边距和行间隙；上下内边距统一为 8pt，内容行高为 16pt、模块总高为 32pt。
- 平台说明下方新增“设置 / Settings”标题行；左侧为标题，右侧为小型 Reset 按钮。最大数量、折叠数量和提示宽度使用 Slider，显示当前数值并沿用既有范围与步进；拖动时即时更新，释放后同步保存。
- 平台说明正下方使用全宽浅黄色评分卡；评分卡上方排列星标与说明文案，下方使用醒目的黑色全宽 Rate Now 行动按钮，并提供右上角关闭按钮。评分卡悬停时不得出现默认黑色描边；行动按钮宽度需与卡片上方内容区域（含关闭按钮）对齐。评分入口在新标签打开 Chrome Web Store，设置标题和配置项位于其下方。关闭后本机隐藏 24 小时，重装扩展后重新显示。
- 亮色模式下全扩展的按钮、Tab、marker、章节 chips、设置复选框、Slider 与焦点反馈使用黑底白字高亮；主 Tab 的非选中悬停态例外，使用玻璃填充色。深色模式保持白底黑字高亮。
- 设置面板使用原生 DOM 的 Card、Slider、Button 与 Separator 语义，并将其 CSS 挂载到设置面板的 Shadow DOM；不得引入 React、HeroUI 或其运行时依赖。仅最外层 Card 使用 Polaris 原有毛玻璃背景、亮色高光描边和阴影；内部 Header、内容区与 Footer 默认背景均透明，并隔离宿主页面样式。Header 保留应用标识，Footer 左侧显示版本号；同步状态不对用户显示。
- 最外层 Card 的玻璃背景必须由半透明底色、渐变内高光、细描边、阴影和背景模糊共同构成，不能退化为透明容器。原生 checkbox、slider、小型 Reset 和联系图标沿用 Hero 风格的半透明表面、选中填充、黑白主题高亮与可见键盘焦点。
- Slider、未选中 checkbox、小型 Reset 与联系图标的默认描边统一使用适配亮暗主题的灰色；checkbox 选中时，外层选项与勾选框均使用相同的主题描边，键盘焦点使用可见 outline。评分卡使用独立的浅黄色语义，并在亮暗主题下保持可读对比。
- 小型 Reset 使用 28pt 高度的胶囊按钮；slider 在 `input` 阶段仅更新轨道进度与数值，拖动结束后才重建导航和写入同步存储，避免滑块因重渲染中断拖动。
- 设置面板外层 Card 必须直接继承顶部 Tab 胶囊的 `--gpt-glass-bg`、`--gpt-glass-border`、`--gpt-glass-shadow`、`--gpt-glass-blur` 与 `--gpt-glass-saturate`，确保亮暗主题下背景设计完全一致；面板仅保留 24pt 圆角和内部布局差异。
- 全局矩形控件统一使用 24pt 大圆角，包括章节弹窗、操作按钮、搜索框、chips、提示卡和设置按钮/选项；胶囊、marker 与图标按钮保持 999px 的全圆角语义，checkbox 勾选框使用与其尺寸匹配的 6pt 圆角。
- Marker 类型筛选使用原生受控 checkbox，直接以 input 的 `change` 事件更新 AI maker 筛选；选中描边、勾选控件和禁用透明度由 label 根节点状态驱动，避免 Shadow DOM 内的组件按压事件失效。

## Marker Queue

- marker 按文档顺序在右侧可滚动队列中显示，项目之间固定 8pt 间距。
- 流式内容驱动 Maker 列表重建时，用户分组、AI Maker、折叠卡片、标题浮层与箭头必须直接保持当前悬停终态，不得重复播放缩放、变色或进场过渡；非流式交互继续使用既有 hover 动效。
- 常规模式下 AI 与用户 maker 正文不截断；文本可在顶部 Tab 胶囊宽度内换行，maker 和悬浮 active marker 的最大宽度均不得超过该宽度。最小化模式下，AI、用户、折叠与悬浮 Maker 标题限制为约 160px 单行，并以省略号表示溢出；用户 Maker 的胶囊额外预留 16px 内边距与 14px 展开/折叠箭头空间，确保标题实际可用宽度仍为 160px；用户箭头使用不可收缩的 8px 盒子，折叠分组最多可扩展至 280px，为计数、余下数量和箭头保留固定空间。完整标题保留在既有 ARIA 标签和悬停提示中。
- 用户消息作为 marker 分组根节点：保留现有 AI marker 顺序，仅按会话页面位置将 section 插入其关联首个 AI marker 前；显示首行摘要、右对齐并使用半透明淡蓝玻璃高亮，文字继承普通 marker 的主题颜色；点击仅展开或收起该消息到下一条用户消息前的连续 AI marker。每个新出现的最新分组即使 AI marker 尚未 ready 也默认展开，此后流式重绘必须尊重用户的手动展开或折叠状态。历史空分组若存在 AI 消息仍允许自由展开或收起，只有确认没有 AI 消息时才显示回复尚未加载提示。
- 同一用户分组内的 AI marker 和数量折叠卡片左对齐，分组宽度必须跟随顶部控制胶囊，不得使用提示宽度向左扩张；没有前置用户消息的 AI marker 保持左对齐且始终可见。搜索命中用户或 AI 内容时，必须显示其所属分组。
- 数量折叠卡片固定使用一行：计数徽标、标题、省略后的剩余数量和展开箭头各自独立；标题只占中间弹性空间并使用省略号，任何长度下均不得换行挤压或重叠。
- “最大数量”限制队列可见高度，超出部分通过队列内部滚动查看。
- 队列在原有扩展命中区内同时支持滚轮/触摸板双指滚动，以及按压后上下拖动；拖动超过阈值后不得触发 marker 点击。
- 点击 marker 后将对应标题元素滚动到会话可视区顶部。
- active marker 离开队列视区时显示可点击的悬浮入口。
- AI maker 数量折叠分组展开后保持原有玻璃背景；悬停时仅增加同色背景不透明度。单条 AI marker、inactive 和 hover 状态保持既有交互。

## Verification

- 检查暗色模式下 marker、设置菜单和按钮为深色玻璃，不再混用浅白玻璃和深色按钮。
- 检查亮色模式下控件仍保持清晰文字、轻描边和白色玻璃背景。
- 检查 tooltip 在暗色和亮色模式下均有足够对比。
- 检查 tooltip 文本在当前提示宽度内换行展示，长英文或连续字符不再显示省略号。
- 检查过滤后没有可见 marker 时，右侧仍保留三 Tab 控制胶囊与设置入口。
- 检查用户 marker 在亮暗模式下均保持淡蓝色语义，且展开/收起不会影响其他用户分组或 AI marker 跳转。
- 在扩展重新加载后保留原页面时，旧 content script 必须断开观察器并移除导航根节点，不得持续产生 `Extension context invalidated` 错误；图标、版本和路由脚本地址必须在启动时缓存，设置面板的原生 DOM 重渲染不得重新访问 Chrome 运行时 API。
- 在小红书主站从 `/ai_chat` 切至普通路由时，检查插件根节点、章节遮罩与滚动锁立即移除；返回 `/ai_chat` 后只重建一套新导航。

## 章节视图

- 章节视图使用带 mask 的中等大小弹窗，正文主宽度收口到约 `524pt`；为保证长文阅读，弹窗表面在亮色模式使用纯白背景、深色模式使用近黑背景，搭配对应细描边和阴影，并保持 24pt 圆角。
- 章节遮罩应保持轻量：亮色模式使用低不透明度冷灰遮罩，深色模式仅适度压暗背景，避免掩盖原页面内容。
- 搜索框、章节 chips、“复制当前章节”“复制全文”和“关闭”使用一致的中等圆角、透明表面、细描边及主题黑白悬浮/选中态；键盘焦点必须清晰可见。
- 章节头部将两种复制操作收纳在“复制”下拉菜单中；菜单项为“复制当前章节”和“复制全文”，选择后自动收起，Escape 优先关闭菜单。
- 正文按 marker section 组织，正文区域一次只显示当前选中章节；chips 点击后必须稳定替换正文并保持选中态，章节搜索、复制和关闭行为不因视觉改造改变。
- 当前章节无可提取正文但保留原页面标题时，空状态下显示居中的“跳转到原会话位置 / Go to original position”按钮；点击后关闭弹窗、恢复页面滚动并跳转标题。无标题的全文兜底空状态只显示提示文案。
- 章节正文必须保留安全的 Markdown 语义：强调、行内代码、链接、引用、列表、代码块与表格均使用原生语义元素渲染；表格区域横向溢出时可滚动，复制操作仍输出纯文本。
- 当网页未渲染完整的 Markdown 管道表格时，章节视图可将其转换为相同的原生表格；仅处理表头、分隔行与数据行列数一致的文本，无法确认结构时保留原段落。
- 章节弹窗底部固定展示 `Shift + ← / →` 的章节切换提示；快捷键在非编辑焦点下循环切换章节、重置正文滚动位置并保持当前 chip 可见，搜索框内保留原生 Shift+方向键文本选择。
- 章节视图需要适配系统深色模式：mask、弹窗底色、正文文字、chips 和按钮都要切到深色语义，不保留亮色硬编码。
